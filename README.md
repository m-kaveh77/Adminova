# ⚡ Adminova

### مدرن • واکنش‌گرا • قدرتمند • داشبورد مدیریت راست‌چین

**Adminova** یک داشبورد مدیریت مدرن و واکنش‌گرا است که با استفاده از **React** و **Tailwind CSS** توسعه داده شده است.

این پروژه با هدف ایجاد یک رابط کاربری تمیز، حرفه‌ای، قابل توسعه و کاربرپسند برای مدیریت بخش‌های مختلف یک نرم‌افزار مانند کاربران، محصولات، تنظیمات و سایر منابع مدیریتی طراحی شده است.

تمرکز اصلی Adminova بر روی یک **رابط کاربری فارسی و راست‌چین (RTL)**، کامپوننت‌های قابل استفاده مجدد، تعاملات روان و تجربه کاربری مدرن است.

---

# 🌐 پشتیبانی از RTL و زبان فارسی

یکی از ویژگی‌های اصلی Adminova، طراحی آن بر اساس ساختار **RTL یا راست‌چین** است.

رابط کاربری پروژه از ابتدا با در نظر گرفتن زبان فارسی طراحی شده و برای زبان‌هایی مانند موارد زیر نیز قابل استفاده است:

🇮🇷 فارسی
🇸🇦 عربی
🌍 سایر زبان‌های راست‌چین

مواردی که در طراحی RTL در نظر گرفته شده‌اند:

* راست‌چین بودن Navigation
* قرارگیری مناسب Sidebar
* راست‌چین بودن محتوای صفحات
* راست‌چین بودن متن‌ها
* جایگذاری مناسب آیکون‌ها
* ساختار مناسب برای رابط فارسی
* سازگاری اجزای UI با زبان‌های RTL

این ویژگی باعث می‌شود Adminova بتواند به‌عنوان پایه‌ای مناسب برای سیستم‌های مدیریتی فارسی مورد استفاده قرار گیرد.

# ⚡ شروع کار با پروژه

## پیش‌نیازها

قبل از اجرای پروژه، اطمینان حاصل کنید که موارد زیر روی سیستم شما نصب شده باشند:

* **Node.js**
* **npm** یا **yarn**
* یک مرورگر مدرن

برای بررسی نصب Node.js:

```bash
node -v
```

برای بررسی نصب npm:

```bash
npm -v
```

---

# 📥 نصب پروژه

ابتدا Repository را Clone کنید:

```bash
git clone https://github.com/your-username/adminova.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd adminova
```

در مرحله بعد وابستگی‌های پروژه را نصب کنید:

```bash
npm install
```

---

# ▶️ اجرای پروژه

برای اجرای پروژه در حالت Development از دستور زیر استفاده کنید:

```bash
npm run dev
```

بعد از اجرای دستور، آدرس نمایش داده شده در Terminal را در مرورگر باز کنید.

معمولاً آدرس پروژه به شکل زیر خواهد بود:

```text
http://localhost:5173
```
